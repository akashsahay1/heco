HECO Portal - Daily Work Report
Date: 23 May 2026

Status: All changes made locally on main branch (not yet committed)


1. CALENDAR BOOKING NOW SHOWS UP
   - A confirmed trip was missing from the calendar because it had
     no end date saved
   - The end date is now filled in automatically from the trip
     length, so bookings always appear
   - Existing trips that were missing an end date have been fixed

2. NATIONALITY ADDED AT SIGN-UP
   - New "Nationality" field on the sign-up form
   - The system now knows automatically whether a traveller is
     Indian or foreign, so the correct pricing is applied
   - All existing travellers have been marked as Indian
   - Google / Facebook sign-ups are asked for it once on first login

3. TRIPS PAGE ERROR FIXED
   - Filtering trips by a status (e.g. "Confirmed") was showing an
     error page instead of the results
   - This now works correctly

4. PAGE NUMBERS ADDED TO ADMIN LISTS
   - Long lists (Trips, Leads, Travellers, Providers, Payments,
     Applications, Regions, Currencies and more) now split into
     pages with clickable page numbers
   - Much easier to browse than one very long list
   - Styled in the HECO brand colour with spacing between numbers
   - Currently set to 10 per page for testing (will move to 20)

5. LOGO IN ALL EMAILS
   - Replaced the plain "HECO Portal" text in emails with the
     HECO logo
   - The logo is built into the email itself, so it always shows
     up, even in Gmail
   - Applies to every email the system sends

6. PRICE-APPROVAL EMAIL TO PROVIDERS
   - When an admin approves a provider's price change, the provider
     now receives a confirmation email automatically
   - The email shows both the old price and the new approved price
