1. HOTEL-STYLE ROOM BOOKING SYSTEM (Biggest update of the day)
----------------------------------------------------------------
- Service Providers (hotels / homestays) can now list their rooms
  like a real hotel - Single Room, Double Room, Twin Room, Triple
  Room, Family Suite, etc.
- Inventory (how many rooms of each type) is stored for every
  property.
- The system automatically tracks how many rooms are available
  on any given date.
- Both Service Providers and Admins see a live calendar showing
  each day's status:
    * How many rooms available
    * How many booked
    * How many blocked
- When a travel agent builds a trip, they can book a specific
  room category along with the quantity.
- Once a trip is confirmed, the booking moves from "held" to
  "confirmed".
- If a trip is cancelled or deleted, the booking is "released"
  and the rooms become available again automatically.
- For multi-night bookings, availability is checked across all
  nights - if even one night is sold out, the entire range is
  blocked.


----------------------------------------------------------------
2. LIVE AVAILABILITY FOR TRAVELLERS
----------------------------------------------------------------
- When a traveller views an experience hosted by a hotel / stay
  property, a new "Stay Options" widget appears on the page.
- The traveller picks check-in and check-out dates, clicks
  "Check Availability".
- They instantly see every room type at that property with its
  live availability, rate per night, and meal plan.
- The AI chat also uses real inventory now when suggesting rooms
  (earlier the AI could invent room types that did not exist).


----------------------------------------------------------------
3. COMFORT TIER SYSTEM (Cat A / B / C / D) - Major Restructure
----------------------------------------------------------------
- Before: Pricing was set per room type
    (one rate for Single Room, another for Double Room, etc.)
- Now: Pricing is set per comfort level
    (one rate for Cat A - Luxury, another for Cat C - Standard,
     and so on)

- Inside each comfort tier the SP can optionally list which room
  types are offered.
- "Quick Setup" button - one click generates one row for each of
  the four tiers; the SP only fills in rate and total rooms.
- "All Tiers" button - from any accommodation row in the list,
  one click opens a modal where every comfort tier's price can
  be edited together.
- On the Admin provider page, the "Comfort Tiers Offered" list is
  now auto-derived from the SP's actual pricing rows
  (no manual multi-select to maintain).


----------------------------------------------------------------
4. SERVICE PROVIDER APPROVAL EMAIL FIX
----------------------------------------------------------------
- Earlier bug: If an admin changed an SP's status to "approved"
  via the Edit form, no email was sent to the SP.
- Fix: Now both paths (the dedicated Approve button AND the Edit
  form) trigger the full approval flow:
    * Email is sent to the SP
    * Login account is created automatically
    * Status updates correctly across the system
